# SECTO GitHub Pages frontend

Upload the contents of this folder to the root of the `secto-learning.github.io` repository.

## Starter Academy update

- 12 original beginner lessons across six courses
- Quick knowledge checks
- Device-local lesson progress
- Safe practice rules and exercises
- Transparent source and further-reading list
- Updated sitemap and robots file
- Existing SECTO logo and visual design preserved

Upload all files and the `_vinext_fonts` folder. When GitHub asks, choose **Commit directly to the main branch**. Do not remove the Google ownership verification HTML file already in the repository.

This is a static frontend. It does not include real accounts, payments, protected courses, a database, or live code execution. Progress is saved only in the learner's browser with local storage.
